# Annotation & Markup Studio Guide

ClipShot comes with an integrated vector annotation studio for editing and redacting screenshots before sharing.

---

## 🛠️ Available Markup Tools

| Tool | Icon | Description |
| :--- | :---: | :--- |
| **Arrow** | `arrow.up.right` | Smooth directional arrow with crisp head markers. |
| **Line** | `line.diagonal` | Straight vector line for connecting elements. |
| **Rectangle** | `rectangle` | Bounding box with customizable stroke width and color. |
| **Ellipse** | `circle` | Oval and circle highlight borders. |
| **Step** | `number.circle.fill` | Auto-incrementing numbered badge (1, 2, 3...) for tutorials and issue reproduction steps. |
| **Pen** | `pencil.tip` | Freehand drawing and sketching. |
| **Text** | `textformat` | Clean typography callouts with font styling. |
| **Highlighter** | `highlighter` | Semi-transparent wash for emphasizing text or table rows. |
| **Blur** | `checkerboard.rectangle` | Gaussian blur for sensitive data (emails, tokens). |
| **Pixelate** | `square.grid.3x3.fill` | Mosaic pixelation for redacting passwords and confidential keys. |

---

## 🚀 Launching the Studio

- **From ClipNotch**: Click the **Edit / Markup** pencil icon when a capture thumbnail appears in the notch capsule.
- **From Floating Preview**: Click the pencil icon on the corner thumbnail.
- **From History Viewer**: Double-click any screenshot or click the **Annotate** button in the inspector.

---

## 💾 Export & Copy

- **`⌘ C`**: Copy annotated image directly to pasteboard with transparency preserved.
- **`⌘ S`**: Save annotated image to disk in full Retina resolution.
