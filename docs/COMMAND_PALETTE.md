# Command Palette (`⌥ Space`) Guide

ClipShot provides a Spotlight-style keyboard command launcher that lets you trigger any action or mode without lifting your fingers from the keyboard.

---

## ⚡ Opening the Palette

- **Global Shortcut**: Press `⌥ Space` (Option-Space) from any app.
- **Menu Bar**: Click the ClipShot menu bar icon and select **Command Palette...**.

---

## 📋 Available Commands

| Command | Shortcut / Keyword | Action |
| :--- | :--- | :--- |
| **Capture Area** | `area`, `crop` | Opens precision crosshair selection. |
| **Capture Window** | `window`, `shadow` | Highlights and captures active application window. |
| **Capture Full Screen** | `screen`, `full` | Captures the entire display. |
| **Extract Text (OCR)** | `ocr`, `text` | Recognizes and copies text from screen selection. |
| **Record Screen** | `record`, `video` | Starts screen recording HUD. |
| **Color Picker** | `color`, `eyedropper` | Activates loupe magnifier and pixel sampler. |
| **Measure Distance** | `measure`, `ruler` | Measures pixel margins and distances. |
| **Screenshot History** | `history`, `recent` | Opens searchable history viewer. |
| **ClipShot Settings** | `settings`, `prefs` | Opens preferences and customization tabs. |

---

## ⌨️ Keyboard Navigation

- **`↑` / `↓`**: Navigate up and down through matching commands.
- **`Enter` / `Return`**: Execute the selected command.
- **`Esc`**: Dismiss the palette.
- **Type**: Real-time fuzzy filtering searches across both command titles and descriptions.
