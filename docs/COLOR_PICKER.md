# Precision Color Picker Guide

ClipShot includes an integrated, high-precision screen color sampling tool designed for designers and front-end developers.

---

## 🎨 Supported Color Formats

| Format | Example Output | Best Used For |
| :--- | :--- | :--- |
| **HEX** (Default) | `#00F5D4` | Web development, Tailwind CSS, Figma |
| **RGB** | `rgb(0, 245, 212)` | Standard CSS stylesheets |
| **HSL** | `hsl(172, 100%, 48%)` | Color palettes and lightness adjustments |
| **Display P3** | `color(display-p3 0.000 0.961 0.831)` | Wide-gamut HDR Apple displays |

---

## 🔍 How to Use

1. **Activate Capture Overlay**: Press `⌘ ⇧ 2` or select "Color Picker" from the menu bar item.
2. **Select Color Picker Mode**: In the overlay toolbar at the bottom of the screen, select the **Color Picker** icon (`eyedropper`).
3. **Inspect Pixels**: Move your cursor over any on-screen element. The **Precision Loupe** magnifies the target region with a crosshair and live color preview.
4. **Click to Sample**: Left-click to copy the color string directly to your clipboard.
5. **Auditory Confirmation**: A subtle audio click confirms the color has been copied to your pasteboard.

---

## 🕒 Recent Swatches & History

Every sampled color is automatically recorded into your recent color swatches in **Settings → Capture**, allowing you to quickly reference previously sampled values without re-sampling.
