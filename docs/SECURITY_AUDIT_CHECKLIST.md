# Security Audit Checklist

This document provides a repeatable verification procedure for auditing ClipShot's security posture and privacy guarantees.

---

## 1. Network Boundary Audit

ClipShot is strictly local-first and must never make unauthorized network connections:

- [ ] **No Outbound Network Calls**: Verify that `URLSession`, `Network.framework`, and `CFNetwork` are not used for telemetry or data egress.
- [ ] **No Third-Party Analytics SDKs**: Confirm absence of Google Analytics, Mixpanel, Sentry, Firebase, or external crash reporting endpoints.
- [ ] **Local-Only Vision OCR**: Verify all `VNRecognizeTextRequest` instances execute purely on the local Apple Neural Engine without remote server calls.

---

## 2. Clipboard Privacy Protections

- [ ] **Password Manager Isolation**: Ensure `ClipboardHistoryManager` checks for `org.nspasteboard.ConcealedType` and `org.nspasteboard.TransientType` to ignore sensitive password manager entries (1Password, Bitwarden, Keychain).
- [ ] **Loop Suppression**: Confirm `org.nspasteboard.AutoGeneratedType` is set when writing screenshots to prevent self-triggering clipboard loops.
- [ ] **Shell Quoting**: Confirm file paths written to pasteboard as text are safely escaped via single-quote wrapping (`'path'`) to prevent command execution if pasted in Terminal.

---

## 3. Sandboxing & File Permissions

- [ ] **Security-Scoped Bookmarks**: Custom folders accessed through user selection must use `URL.bookmarkData(options: .withSecurityScope, ...)`.
- [ ] **Graceful TCC Rejection**: Denying Screen Recording or Accessibility permissions in macOS System Settings must never crash the app; informative permission guidance prompts must be displayed instead.
- [ ] **Diagnostic Log Sanitization**: Verify `AppLogger` records only system event levels and never logs screenshot pixel data, file contents, or recognized OCR text.
