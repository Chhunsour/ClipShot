# ClipShot Keyboard Shortcuts Reference

ClipShot offers a blend of global system shortcuts, native macOS integrations, and granular keyboard navigation controls within the interactive capture overlay.

---

## 🌐 Global Hotkeys

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `⌘ ⇧ 2` | **Capture Overlay** | Opens the precision crosshair HUD with loupe magnifier, color picker, and dimension readout. |
| `⌘ ⇧ 4` | **macOS Area Capture** | Native macOS selection capture; ClipShot detects and copies the image to the clipboard in `< 100ms`. |
| `⌘ ⇧ 3` | **macOS Full Screen** | Native macOS full-screen capture; instantly copied to the clipboard. |
| `⌘ ⇧ H` | **Screenshot History** | Opens the searchable capture history archive with thumbnail preview. |
| `⌥ Space` | **Command Palette** | Launches the Spotlight-style command palette to search and trigger actions. |
| `⌘ V` | **Universal Paste** | Paste the captured screenshot directly into any target app (Slack, Discord, Figma, etc.). |

*(Global shortcuts can be customized in **Settings → General**).*

---

## 🎯 Precision Capture Overlay Controls

When the capture overlay is active (`⌘ ⇧ 2`), you can use the following keys for pixel-perfect adjustments:

| Key / Shortcut | Action |
| :--- | :--- |
| `Esc` | Cancel capture overlay and close HUD. |
| `Enter` / `Return` | Confirm and capture the active selection area. |
| `←` / `→` / `↑` / `↓` | Nudge selection rectangle by **1 pixel** in the respective direction. |
| `⇧` + `Arrow Keys` | Nudge selection rectangle by **10 pixels** for faster alignment. |
| `Click & Drag` | Draw selection rectangle with live pixel dimension readout ($W \times H$). |

---

## 🎨 Overlay Toolbar Modes

Inside the floating overlay toolbar, you can switch modes:
- **Area Capture**: Standard rectangular marquee selection with 8 resize handles.
- **Window Capture**: Automatically highlights the window under the cursor with clean system drop shadows.
- **Full Screen**: Captures the entire display with one click.
- **Color Picker**: Magnifies screen pixels and samples HEX, RGB, and HSL color values.
- **Measure Tool**: Measures on-screen distances and bounding margins in pixels.
- **Scrolling Capture**: Stitches scrollable windows or documents into a single image.
