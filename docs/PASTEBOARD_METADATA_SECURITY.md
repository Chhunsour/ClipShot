# Pasteboard Metadata Security & Privacy Architecture

The macOS system clipboard (`NSPasteboard.general`) is a shared inter-process communication bus accessible by any active user application. Clipboard managers and utilities that monitor pasteboard changes must implement rigorous safeguards to prevent accidental retention of sensitive data—such as passwords, multi-factor authentication (MFA) codes, and session tokens.

This document describes ClipShot's clipboard security architecture and pasteboard type handling conventions.

---

## 1. Industry Standard Pasteboard Privacy Flags

Major macOS password managers and security software adhere to standard private pasteboard types defined by the macOS developer community:

| Pasteboard Type Identifier | Primary Originators | ClipShot Ingestion Behavior |
| :--- | :--- | :--- |
| **`org.nspasteboard.ConcealedType`** | 1Password, Bitwarden, KeePass, Apple Keychain | **IGNORED COMPLETELY**. Never read, logged, or recorded into history. |
| **`org.nspasteboard.TransientType`** | Authenticator apps, Terminal sudo utilities | **IGNORED COMPLETELY**. Treated as ephemeral and volatile. |
| **`org.nspasteboard.AutoGeneratedType`** | ClipShot, TextExpander, Raycast, Alfred | **ANTI-LOOP FILTER**. Updates current preview item without appending duplicate history. |

## 2. Privacy Preservation Pipeline

When `ClipboardHistoryManager` detects a change in `pasteboard.changeCount`, it performs an immediate security audit before reading any payload data:

```swift
func checkForChanges() {
    guard pasteboard.changeCount != lastChangeCount else { return }
    lastChangeCount = pasteboard.changeCount

    let availableTypes = Set(pasteboard.types ?? [])
    
    // 1. Zero-trust security check: reject sensitive credentials immediately
    let protectedTypes = [
        NSPasteboard.PasteboardType("org.nspasteboard.ConcealedType"),
        NSPasteboard.PasteboardType("org.nspasteboard.TransientType")
    ]
    guard protectedTypes.allSatisfy({ !availableTypes.contains($0) }) else {
        // Discard without reading strings or bitmap bytes
        return
    }

    // 2. Loop suppression for synthetic clipboard updates
    if availableTypes.contains(autoGeneratedType) {
        currentItem = imageItemFromPasteboard()
        return
    }

    // 3. Normal user text and image processing...
}
```

### Key Security Guarantees:
1. **Zero Memory Retention**: Passwords and secrets are never initialized into Swift `String` or `Data` objects inside ClipShot.
2. **Zero Disk Leakage**: Neither thumbnail caches nor disk logs ever receive entries originating from password managers.
3. **No Network Transmission**: ClipShot operates completely offline with zero analytics, telemetry, or remote transmission.

## 3. ClipShot Output Telemetry (`AutoGeneratedType`)

When ClipShot copies a captured screenshot or cropped selection to `NSPasteboard.general`, it stamps the item with `org.nspasteboard.AutoGeneratedType`:

```swift
private func addScreenshotMetadata(to item: NSPasteboardItem, fileURL: URL?) {
    item.setString("1", forType: NSPasteboard.PasteboardType("org.nspasteboard.AutoGeneratedType"))
    guard let fileURL else { return }
    item.setString(fileURL.absoluteString, forType: .fileURL)
    item.setString(shellQuoted(fileURL.path), forType: .string)
}
```

### Benefits:
- **Prevents Infinite Capture Loops**: ClipShot's own background polling listener recognizes the item as internally generated and updates the active selection preview without duplicating history rows.
- **Third-Party Compatibility**: Third-party clipboard utilities (e.g. Paste, Maccy, Raycast) respect this flag and can differentiate automated captures from intentional user clipboard actions.

Clipboard privacy compliance is verified via automated unit tests:
